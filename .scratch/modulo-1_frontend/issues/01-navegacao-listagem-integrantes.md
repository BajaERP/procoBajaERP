# 01: Navegação e consulta inicial de integrantes

Status: ready-for-human

**Blocked by:** Nenhum.

## O que construir

Permitir acessar o módulo pela sidebar e consultar integrantes com dados demonstrativos, mantendo a produção indisponível até a integração.

- [x] Remover os subitens de todos os módulos da sidebar, preservando suas entradas principais, e oferecer navegação interna entre Integrantes e Subsistemas.
- [x] Exibir lista de integrantes com busca, filtros e estados de carregamento, vazio e erro; o Gestor demonstrativo inicial consulta apenas dados permitidos.
- [x] Separar os dados fictícios em uma área própria e acessá-los por uma interface de serviços substituível; não importar mocks diretamente nas telas.
- [x] No build de produção, apresentar o módulo como indisponível, sem operações demonstrativas.
- [x] Seguir o Figma e o design system, com temas claro e escuro, responsividade desde 320 px, teclado, foco e drawer acessíveis. Atualizar documentação de navegação afetada.
- [x] Verificar a interface no navegador e executar as verificações de formatação e build do frontend.

Consulte a [especificação do módulo](../spec.md) para as regras completas, o Figma e os critérios transversais de interface e verificação.
