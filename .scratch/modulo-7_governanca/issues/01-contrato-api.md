# 01: Fechar o contrato compartilhado

Status: ready-for-agent
Frente: Compartilhada

**Especificação:** [Módulo 7 · Governança](../spec.md).

**Blocked by:** Nenhuma issue nova.

## Entrega

Acordar a API e exemplos de dados suficientes para desenvolver os fluxos de Governança em paralelo.

## Critérios de aceitação

- [ ] Definir busca, biblioteca, detalhe, histórico, campos de Documento e Versão, estados de Rascunho e Vigência e capacidades por Perfil.
- [ ] Definir comandos de edição, marcação, publicação, encerramento e cancelamento. Acordar datas com fuso explícito, o tratamento de uma revisão desatualizada e as respostas de validação, autorização, conflito e indisponibilidade.
- [ ] Definir Ciência, Aceite, comprovante, acompanhamento da equipe e consulta pessoal, com exemplos para Ciência sem Aceite, ingresso, reativação, Versão futura, cancelamento e histórico.
- [ ] Fixar o contrato de pendências pessoais para o Dashboard, com Documento, Versão, início da Vigência e referência para abertura. Fornecer exemplos para mocks e testes usando a sessão, HTTP e CSRF do ERP.

## Limite de escopo

Usar o esquema existente da develop (DBML v6, Flyway V1–V11). Alterações de esquema e novas migrações ficam fora desta issue.
