# Diagramas e modelo de dados

Esta pasta reúne modelos e diagramas de análise. Para consultar o esquema em execução, use a [sequência Flyway V1 a V11](../../backend/src/main/resources/db/migration/). A [modelagem do projeto](../projeto/modelagem.md) explica a relação entre o DBML, os diagramas e a aplicação.

- Use o [DBML v6](Diagramas%20de%20Banco%20de%20Dados/modelo_relacional_v6.dbml) para ler o modelo relacional vigente. A [pasta de banco de dados](Diagramas%20de%20Banco%20de%20Dados/) preserva o DBML e o SQL v5 e as figuras históricas. Para a atribuição financeira vigente, consulte o [ADR 0002](../adr/0002-gestor-financeiro-derivado-do-subsistema.md).
- Consulte os [casos de uso](Diagramas%20de%20Caso%20de%20Uso/) e os [diagramas de classes](Diagramas%20de%20Classe/) para visualizar a análise de cada módulo. As duas pastas têm arquivos editáveis Draw.io e imagens.
- Consulte o [documento de projeto](../projeto/documento-de-projeto.pdf) para a referência acadêmica com requisitos, dicionário, protótipos e diagramas.

O [índice dos módulos](../projeto/modulos/README.md) relaciona cada área aos requisitos e diagramas correspondentes. Para funcionamento atual, consulte as arquiteturas do [frontend](../../frontend/ARCHITECTURE.md) e do [backend](../../backend/ARCHITECTURE.md).
